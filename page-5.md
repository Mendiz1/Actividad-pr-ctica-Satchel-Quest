# What's special about my Hero?

Each hero starts with a few extra chips in their starting Satchel:

- Fighter - Sword and Shield
- Rogue - Coin and Bow
- Alchemist - Potion and Staff
- Wizard - Coin and Staff

In addition, each Hero has 2 unique starting skills, and 12 level up skills. Each game, you randomly build a skill tree using only 8 of the 12 level up skills, so even games with the same hero will present you with different options.
